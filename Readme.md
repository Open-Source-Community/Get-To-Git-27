
# 🚀 Get to Git

Welcome to **Get to Git**, an event organized by the **OSC (Open Source Community)** to help you understand Git and get comfortable using it in your open-source journey.

This event consists of **two sessions** designed to take you from the basics of Git to collaborating on projects like a pro!

## 📚 Sessions Overview

### Session 1: Git Basics & Core Concepts

In this session, we'll introduce Git and explore the fundamental concepts you need to start using it confidently.

You'll learn about:
- What is Git and why do we use it?
- Understanding repositories and version control.
- Initializing a repository and tracking changes.
- Making commits and understanding the Git workflow.
- Essential Git commands and how to use them.

### Session 2: Branching, Merging & Collaboration

In the second session, we'll dive deeper into Git and explore how developers collaborate on projects.

You'll learn about:
- Creating and managing branches.
- Switching between branches.
- Merging branches.
- Understanding and resolving merge conflicts.
- What are Pull Requests (PRs) and how to create them.
- How Git supports collaboration in open-source projects.
